📷 Pretty pictures — two ways

  
Your 3D view can become real pictures. Easiest first:

  

    1 · In the browser — nothing to set up
    
Open the 3D view, go to Export and press 📷 Render. The image sharpens over time; press Render again to stop and keep it.

  

  

    2 · With Blender — photorealistic
    
Blender is a free, professional 3D program. Set it up once — after that every render is one click:

    

      
… Run House Planner as the desktop app
        
Download it from the releases page and start House Planner from the Start menu — then open this guide again.

      
… Install Blender (free)
        
Get it at blender.org — or open a terminal and run: winget install BlenderFoundation.Blender. Then reopen this guide.

      
… Tell House Planner to use Blender
        

      
4️⃣ Press 📷 Render in the Export tab — the finished picture opens right here in the app. Fast = quick draft, Fine = final quality.

    

  

  
Tip: turn on 🏠 Roof (View tab) before interior renders, so the light is right.
